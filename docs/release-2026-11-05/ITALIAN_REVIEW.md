# Driver Italian catalog — 5 November 2026

Added AI-drafted Italian values for all 1,216 initially missing English driver keys. A native sample then exposed keys absent from English itself: 39 source-used keys were added across all six languages, with 34 more Italian values and five existing Italian values preserved. All existing Italian values and 799 legacy keys were retained; five of those keys now have an English source counterpart, leaving 794 extra keys. No translation service, paid translation API, external reviewer or human translation review was used. This is draft content awaiting human acceptance, including financial/consent/safety terminology and the existing translated values.

`npm run translations:check` recursively compares all English leaves with all six catalogs, validates nonempty strings, and checks exact double-brace interpolation and legacy single-brace expression tokens. All six pass with 1,754 source leaves, zero missing and zero placeholder mismatches. Italian has 2,548 leaves including 794 preserved extra keys. Source AST validation also checks literal and conditional translation keys used by non-test source files, preventing omissions shared by every catalog. The check does not treat extra legacy customer keys as driver coverage. Existing Arabic and Spanish translations each had a modified `distanceMeters...toFixed(2)` expression; only those expression tokens were restored.

The check proves structure and placeholder preservation. It cannot establish correctness, idiomatic Italian, legal meaning, displayed interpolated values, screen fit, accessibility, font scaling or RTL behavior. The native staging APK includes the catalog, but screen samples are separate acceptance evidence. Complete six-language/RTL and accessibility journeys remain open.
