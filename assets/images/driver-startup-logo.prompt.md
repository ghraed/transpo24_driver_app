# Driver startup logo

Created using the built-in image generation tool. The final asset uses an opaque black background matching the launch screen; transparent drafts were rejected for edge artifacts. The launcher icon remains separate.

## Final prompt

Create one finished flat minimalist mobile splash logo image, square 1024x1024. Background EXACTLY solid black #000000, fully opaque, uniform edge to edge. In the center, a small crisp flat pure white silhouette of a seated driver wearing a baseball cap facing right and holding a steering wheel, three short speed lines behind the seat. Below it the exact text "Transpo24" in smaller clean white medium-weight sans-serif lettering with generous clear spacing above. Entire symbol-and-wordmark group centered optically and occupies the middle 60% of canvas height. Symbol width 60% of canvas, wordmark width 46%. Preserve generous BLACK empty space on every side. All white shapes solid flat opaque white, clean smooth precision edges like a professionally drawn vector brand mark. NO transparency, no alpha cutout, no texture, no grain, no scatter, no gradients, no shadows, no outlines, no 3D, no yellow, no frames, no extra objects, no mockup. The image should blend seamlessly into a pure-black phone launch screen.
